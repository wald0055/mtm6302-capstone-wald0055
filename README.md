part-4 report:
This project is a two-page NASA Astronomy Picture of the Day (APOD) web application designed to let users browse space images and save their favourites. The main page loads the current day’s APOD using the NASA API and includes a date picker that allows users to view images from any chosen date. When an APOD is loaded, the page displays the image, title, and explanation in a clean, styled layout. A “Save to Favourites” button stores the currently viewed APOD in the browser’s localStorage, allowing users to return to it later. The Saved page automatically retrieves and displays all saved APODs in a responsive grid format. If no items are saved, the page shows a clear message to guide the user. The project focuses on giving users a smooth and easy way to view NASA's APOD.
