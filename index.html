About the project

This website is a personal project built to showcase NASA's Astronomy Picture of the Day (APOD) using the official NASA API. Each day, NASA publishes a breathtaking image or video from space, accompanied by a short explanation written by a professional astronomer. This site provides a clean, user-friendly interface to explore these daily space highlights, whether you're a space enthusiast, a student, or just curious about the universe.
